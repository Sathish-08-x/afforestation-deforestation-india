### Web Portal Features
- **Living Nature Canvas:** Interactive green falling leaves & bioluminescent spore particles that react to mouse hover.
- **Ecological Analyzer:** Interactive Native Indian Trees (Peepal, Neem, Banyan, Khejri) vs. Commercial Eucalyptus Monoculture comparison.
- **Embedded Media Players:** Direct browser streaming for both project video deliverables.
- **Official Satellite & Government Data:** Forest Survey of India (ISFR), CAMPA Act telemetry, Aravalli Green Wall, and Miyawaki forestry breakdown.
